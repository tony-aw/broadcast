Details on Broadcasted Operators

Description

Base 'R' comes with relational, arithmetic, integer, logical, and bit-wise operators.
'broadcast' provides 2 ways to use these operators with broadcasting.

The first (and simple) way is to use the [broadcaster](broadcaster.qmd) class, which comes with it's own method dispatch for the above mentioned operators.
This approach supports operator precedence, and for the average 'R' user, this is sufficient.

The second way is to use the large set of bc.- functions.
These offer much greater control and more operators than the previous method, and has less risk of running into conflicting methods.
But they do not support operator precedence.

Operators Overloaded via Broadcaster Class

The 'broadcast' package provides the [broadcaster](broadcaster.qmd) class, which comes with its own method dispatch for the base operators.
If at least one of the 2 arguments of the base operators has the [broadcaster](broadcaster.qmd) class attribute, and no other class (like bit64) interferes, broadcasting will be used.

The following operators have a 'broadcaster' method: 

# Group      : Operators             ; Comments
# relational : ==, !=, <, >, <=, >=  ;
# arithmetic : +, -, *, /, ^         ;
# integer    : %%, %/%               ; both sides will be truncated
# logical    : &, |                  ;
# bit-wise   : &, |                  ; if both sides are type of `raw`

See also the Examples section below.
Unary operations (i.e. + x, - x) return the original object, with only the sign adjusted.

Available bc. functions

'broadcast' provides a set of functions for broadcasted element-wise binary operations with broadcasting.
These functions use an API similar to the outer function.

The following functions for simple operations are available:

  • [bc.rel](bc.rel.qmd): General relational operations (⁠==, !=, <, >, <=, >=⁠).
    The various other bc. methods below have specialised relational operators available for specialised needs.

  • [bc.b](bc.b.qmd): Boolean/logical operations;

  • [bc.i](bc.i.qmd): integer operations;

  • [bc.d](bc.d.qmd): decimal arithmetic operations;

  • [bc.cplx](bc.cplx.qmd): complex arithmetic operations;

  • [bc.str](bc.str.qmd): string (in)equality, concatenation, and distance operations;

  • [bc.raw](bc.raw.qmd): operations that take in arrays of type raw and return an array of type raw;

  • [bc.bit](bc.bit.qmd): BIT-WISE operations, supporting the raw and integer types;

  • [bc.list](bc.list.qmd): apply any 'R' function to 2 recursive arrays with broadcasting.

Examples


# maths ====

x <- 1:10
y <- 1:10
dim(x) <- c(10, 1)
dim(y) <- c(1, 10)
broadcaster(x) <- TRUE
broadcaster(y) <- TRUE



x + y / x
(x + y) / x

(x + y) * x


# relational operators ====
x <- 1:10
y <- array(1:10, c(1, 10))
broadcaster(x) <- TRUE
broadcaster(y) <- TRUE

x == y
x != y
x < y
x > y
x <= y
x >= y




# maths ====

x <- sample(1:10)
y <- sample(1:10)
dim(x) <- c(10, 1)
dim(y) <- c(1, 10)
mbroadcasters(c("x", "y"), TRUE)



x + y / x
(x + y) / x

(x + y) * x
