bc.listR Documentation

Broadcasted Operations for Recursive Arrays

Description

The bc.list() function performs broadcasted operations on 2 Recursive arrays.

Usage

bc.list(x, y, f, ...)

## S4 method for signature 'ANY'
bc.list(x, y, f)

Arguments

x, y

conformable Recursive arrays (i.e. arrays of type list).

f

a function that takes in exactly 2 arguments, and returns a result that can be stored in a single element of a list.

...

further arguments passed to or from methods.

Value

A recursive array.

See Also

[broadcast_operators](aaa01_broadcast_operators.qmd)

Examples


x.dim <- c(10, 2,2)
x.len <- prod(x.dim)

gen <- function(n) sample(list(letters, month.abb, 1:10), n, TRUE)

x <- array(gen(10), x.dim)
y <- array(gen(10), c(10,1,1))

bc.list(
  x, y,
  \(x, y)c(length(x) == length(y), typeof(x) == typeof(y))
)
