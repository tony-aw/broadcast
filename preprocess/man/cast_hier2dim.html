cast_hier2dimR Documentation

Cast Hierarchical List into Dimensional list

Description

cast_hier2dim() casts a hierarchical list into a dimensional list (i.e. into a recursive array).
hier2dim() takes a hierarchical list, and predicts what dimensions the list would have, if re-casted by the cast_hier2dim() function.

Usage

cast_hier2dim(x, ...)

hier2dim(x, ...)

## Default S3 method:
cast_hier2dim(x, in2out = TRUE, maxdepth = 16L, recurse_classed = FALSE, ...)

## Default S3 method:
hier2dim(x, in2out = TRUE, maxdepth = 16L, recurse_classed = FALSE, ...)

Arguments

x

a list.
If x has redundant nesting, it is advisable (though not necessary) to reduce the redundant nesting using [dropnests](dropnests.qmd).

...

further arguments passed to or from methods.

in2out

see broadcast_casting.

maxdepth

a single, positive integer, giving the maximum depth to drop nesting in.
The surface-level elements of a list is depth 1, so maxdepth must be ⁠>= 2⁠.

recurse_classed

TRUE or FALSE, indicating if the function should also recurse through classed lists within x, like data.frames.

Value

For cast_hier2dim():
A recursive array (i.e. a dimensional list).

For hier2dim():
An integer vector, giving the dimensions x would have, if re-casted by cast_hier2dim().

Examples


# ideal scenario ====
x <- list(
  group1 = list(
    id1 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    id2 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    id3 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    )
  ),
  group2 = list(
    id1 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    id2 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    id3 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    )
  )
)

print(x)

hier2dim(x) # predict what dimensions `x` would have if casted as dimensional
x2 <- cast_hier2dim(x) # cast as dimensional

# since the original list uses the same names for all elements within the same depth,
# dimnames can be set easily:
dimnames(x2) <- list(
  names( x[[1]][[1]] ),
  names( x[[1]] ),
  names( x )
)
print(x2) # very compact, maybe too compact...?

# print a small portion of the list, but less compact:
cast_dim2flat(x2[, 1:2, "group1", drop = FALSE])
