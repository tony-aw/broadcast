bc.rawR Documentation

Broadcasted Operations on Raw Arrays

Description

The bc.raw() function performs broadcasted (in)equality operations and bit-wise operations on arrays of type raw.

Usage

bc.raw(x, y, op)

Arguments

x, y

conformable raw vectors or arrays.

op

a single string, giving the operator.
Supported bit-wise operators: &, |.
Supported relational operators: ==, !=, <, >, <=, >=.
Supported basic arithmetic operators (see details section for more info): +, -, *, pmin, pmax.

Details

The basic arithmetic operators treat the raw type as unsigned 8-bit integers without missing value support.
The unsigned 8-bit integer supports values from 0 to 255.
Using the raw type as 8-bit integers may be useful when dealing with very large arrays filled with small non-negative integers:
The raw type takes in 4 times less memory than 32-bit integers, and 8 times less memory than 53-bit integers and doubles.

Overflow is handled in the same way as it is handled in pure 'C' code.
For example, as.raw(255) + as.raw(2) equals as.raw(1).

Value

For bit-wise operators:
A array of type raw, as a result of the broadcasted bit-wise operation.

For relational operators:
A logical array as a result of the broadcasted integer relational comparison.

For the basic arithmetic operators:
A array of type raw, as a result of the broadcasted basic arithmetic operation.

Examples

x.dim <- c(4:2)
x.len <- prod(x.dim)
x.data <- as.raw(0:10)
y.data <- as.raw(10:0)
x <- array(x.data, x.dim)
y <- array(y.data, c(4,1,1))

bc.raw(x, y, "==")
bc.raw(x, y, "!=")

bc.raw(x, y, "&")
bc.raw(x, y, "|")
