broadcasterR Documentation

Check or Set if an Array is a Broadcaster

Description

broadcaster() checks if an array is of class "broadcaster".
⁠broadcaster()<-⁠ sets or un-sets the class attribute "broadcaster" on an array.

The broadcaster class is a simple (or "lazy") class, and exists purely to overload the math, Boolean, and relational infix operators to support broadcasting.
This makes mathematical expressions with multiple variables, where precedence may be important, far more convenient.
Like in the following calculation:
x / (y + z)

The broadcaster class comes with its own method dispatch for the base operators.
If at least one of the 2 arguments of the base operators is of class broadcaster, and no other class (like bit64) interferes, broadcasting will occur in the same manner as used in the various ⁠bc.*⁠ - functions.

Usage

broadcaster(x)

broadcaster(x) <- value

Arguments

x

object to check or set.

value

set to TRUE to make an array a broadcaster, or FALSE to remove the broadcaster class attribute from an array.

Value

For broadcaster():
TRUE if an array or vector is a broadcaster, or FALSE if it is not.

For ⁠broadcaster()<-⁠:
Returns nothing, but sets (if right hand side is TRUE) or removes (if right hand side is TRUE) the "broadcaster" class attribute.

Examples



x <- 1:10
broadcaster(x) <- TRUE

y <- 1:10
broadcaster(y) <- TRUE

x + y / x
x + 1 # mathematically equivalent to the above, since x == y
(x + y) / x
2 * x/x # mathematically equivalent to the above, since x == y

dim(x) <- c(10, 1)
dim(y) <- c(1, 10)

x + y / x
(x + y) / x

(x + y) * x
