Casting Explained

1 Introduction

Hierarchical data is surprisingly common, and are commonly represented in by nested lists.

Broadcasted operations can be performed over dimensions, but not through nesting or hierarchies.
Therefore, it is useful to be able to cast nested lists into dimensional lists.
The ‘broadcast’ package provides the cast_hier2dim() function, to cast nested lists into dimensional lists, and the cast_dim2hier() to cast dimensional lists back to nested lists.

Casting between nested and dimensional lists is not only useful for broadcasting, however.
Casting nested lists to dimensional lists has its own merits, as dimensional lists have some advantages over nested lists beside the broadcasting, such as the following:

  • Performing sub-set operations on multiple recursive subsets (using the [[ and [[<- operators) requires a (potentially slow) loop, whereas multi-dimensional subsets (using operator forms like [..., ...] and [..., ...]<-) are vectorized and generally much faster.
  • Re-organizing recursive arrays is generally much easier, faster, and more straight-forward than re-organizing nested lists.

This Vignette explains the functions ‘broadcast’ provides to cast between nested and dimensional lists.

 

2 Cast Evenly Nested List to Dimensional List

2.1 Introduction

The “ideal” use-case for cast_hier2dim() is when you have an evenly nested list - like the following list:

x <- list(
  group1 = list(
    class1 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    class2 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    )
  ),
  group2 = list(
    class1 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    class2 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    )
  )
)

The above list is evenly nested, because all “group#” elements consists of the same number of “class#” elements each, and all “class#” elements consist of the same number of variables (height, weight, and sex) each.

Suppose you have 2 lists like the one above, and want to do a broadcasted operation on them. Like using some measurement to determine the difference in the elements of both lists.
Broadcasting, as stated earlier, only works over dimensions, not through nesting.
A list like x thus needs to become a dimensional list, rather than a nested list.
And that’s what the cast_hier2dim() function does: it re-casts a nested list to a dimensional list.

Let’s try this out on list x.

 

2.2 hier2dim()

Before actually casting x into a dimensional list, one may want to know what the dimensions will become when casted as a dimensional list;
The hier2dim() functions does that:

hier2dim(x)
#> no padding no padding no padding 
#>          3          2          2

It returns c(3, 2, 2).
Notice all elements are named “no padding”.
This means that, when x is casted as dimensional list, no elements will be added (no “padding”).
No padding is needed because x is an evenly nested list.

cast_hier2dim() has an argument called in2out, which is set to TRUE by default.
This means cast_hier2dim() will by default cast the inner most elements to the rows, and elements of the depth above that to the columns, and so on until the surface-level elements become the last dimensions.
x has 3 elements at its deepest level for all iterations: height, weight, and sex; so those will become the rows.
x has 2 elements at the second-deepest level for all iterations of the list: class1, class2; so those will become the columns.
Finally x itself has 2 elements: group1 and group2, so those will become the last dimension (the layers).

If the element ordering described above is not desired, one can set in2out to FALSE.
If in2out = FALSE, the surface elements (in this case the “group#” elements) become the rows, the elements at one depth deeper (“class#”) become the columns, and the elements yet another level deeper (height, weight, sex) become the layers (i.e. third dimension), and so on:

hier2dim(x, in2out = FALSE)
#> no padding no padding no padding 
#>          2          2          3

2.3 Cast in to out

Let’s now cast x as a dimensional list:

hier2dim(x) # check once again the dimensions
#> no padding no padding no padding 
#>          3          2          2
x2 <- cast_hier2dim(x) # actually cast nested list into dimensional list
print(x2)
#> , , 1
#> 
#>      [,1]         [,2]        
#> [1,] numeric,10   numeric,10  
#> [2,] numeric,10   numeric,10  
#> [3,] character,10 character,10
#> 
#> , , 2
#> 
#>      [,1]         [,2]        
#> [1,] numeric,10   numeric,10  
#> [2,] numeric,10   numeric,10  
#> [3,] character,10 character,10

x2 is the casted list. Since in2out = TRUE, element x[[i]][[j]][[k]] corresponds to element x2[k, j, i] (for all i, j, and k).

cast_hier2dim() will not preserve names, as there is no guarantee that the names of all elements over iterations within the same depth will have the same names.
But in this case, it is known the names as consistent, so x2 can very easily be given dimensional names, like so:

# remember: in2out = TRUE
# so we go from the deepest names to the surface names
dimnames(x2) <- list(
  names(x[[1]][[1]]),
  names(x[[1]]),
  names(x)
)
print(x2)
#> , , group1
#> 
#>        class1       class2      
#> height numeric,10   numeric,10  
#> weight numeric,10   numeric,10  
#> sex    character,10 character,10
#> 
#> , , group2
#> 
#>        class1       class2      
#> height numeric,10   numeric,10  
#> weight numeric,10   numeric,10  
#> sex    character,10 character,10

There, the names are now correct.

As shown above, will display a dimensional list more compactly than a nested list.
Depending on the situation this may be either be desirable or undesirable.

One can print x2 less compactly without much effort by flattening it, using the cast_dim2flat() function.
We only need to see a portion of the list in detail, so let’s look at class1 from group 1 in the flattened form:

cast_dim2flat(x2[, 1, "group1", drop = FALSE])
#> $`['height', 'class1', 'group1']`
#>  [1] 170.0094 169.1459 170.3714 171.6441 169.0427 170.6247 169.5903 170.7899
#>  [9] 166.1695 172.4196
#> 
#> $`['weight', 'class1', 'group1']`
#>  [1] 80.83811 79.31704 81.93432 79.01855 79.61695 77.72917 79.48546 81.50405
#>  [9] 83.02080 81.50054
#> 
#> $`['sex', 'class1', 'group1']`
#>  [1] "M" "F" "M" "F" NA  NA  NA  "M" "M" "F"

 

2.4 Cast from out to in

Let’s cast x again, but this time set the argument in2out = FALSE.

hier2dim(x, in2out = FALSE) # check once again the dimensions

#> 
#>      [,1]       [,2]

#> [2,] numeric,10 numeric,10

#> 
#>      [,1]       [,2]

x2 is the casted list. Since in2out = FALSE, element x[[i]][[j]][[k]] corresponds to element x2[i, j, k] (for all i, j, and k).

3 Cast Unevenly Nested List to Dimensional List

In the previous section, the ideal scenario of an evenly nested list was used.
But the cast_hier2dim() and hier2dim() functions also work on nested lists with uneven nesting.

Take for example the following list:

x <- list(
  group1 = list(
    class1 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    class2 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    )
  ),
  group2 = list(
    class1 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    class2 = list(
      height = rnorm(10, 170),
      sex = sample(c("M", "F", NA), 10, TRUE)
    ),
    class3 = list(
      height = rnorm(10, 170),
      weight = rnorm(10, 80),
      sex = sample(c("M", "F", NA), 10, TRUE)
    )
  )
)

The above list is UNEVENLY nested:

  • not all groups (surface level, or depth = 1) have the same number of classes.
  • not all classes (depth = 2) have the same number of variables: x\(group2\)class2 is missing the variable “weight”.

Checking what dimensions the casted list will have gives the following:

hier2dim(x)
#>    padding    padding no padding 
#>          3          3          2

The hier2dim().

Let’s cast x:

x2 <- cast_hier2dim(x)
print(x2)
#> , , 1
#> 
#>      [,1]         [,2]         [,3]
#> [1,] numeric,10   numeric,10   NULL
#> [2,] numeric,10   numeric,10   NULL
#> [3,] character,10 character,10 NULL
#> 
#> , , 2
#> 
#>      [,1]         [,2]         [,3]        
#> [1,] numeric,10   numeric,10   numeric,10  
#> [2,] numeric,10   character,10 numeric,10  
#> [3,] character,10 NULL         character,10

x2 has more NULL values than x.
The NULL values are added for padding, as all slices of the same dimension need to have the same number of elements.
For example, all rows need to have the same number of columns.

5 Additional Details

5.1 Why nested broadcasting does not work

You can perform broadcasted operations along dimensions of a dimensional list (for example using bc.list(), bcapply()), but you can’t really perform broadcasted operations along the depths or recursive nests of a nested list.

Broadcasting along recursive nests of a nested lists, has several issues.
One glaring issue is that broadcasting requires matching lengths (i.e. row 1 in an array has as many columns as row 2), but matching lengths cannot be guaranteed on a nested list:
A nested list may have, for example, 5 elements in one nested subset of a certain depth, and 4 elements on another nested subset of the same depth.
So broadcasting can’t work recursively like that.

 

5.2 Nested VS Dimensional Sub-set operations

Let’s start with 2 lists, x and y, with essentially the same content, but x is a nested list, and y is a dimensional list:

x <- list(
  A = list(
    A = "AA",
    B = "AB"
  ),
  B = list(
    A = "BA",
    B = "BB"
  )
)

y <- list(
  "AA", "AB", "BA", "BB"
)
dim(y) <- c(2,2)


print(x)
#> $A
#> $A$A
#> [1] "AA"
#> 
#> $A$B
#> [1] "AB"
#> 
#> 
#> $B
#> $B$A
#> [1] "BA"
#> 
#> $B$B
#> [1] "BB"
print(y)
#>      [,1] [,2]
#> [1,] "AA" "BA"
#> [2,] "AB" "BB"

Selecting multiple nested subsets requires a slow loop, but selecting multiple dimensional elements is vectorized and much faster.

For example, to get elements “AB” and “BB”, you need to do the following:

# for nested list x:
for(i in 1:2) {
  x[[i]][[2]] |> print()
}
#> [1] "AB"
#> [1] "BB"

# for dimensional list y:
y[2,] # much faster
#> [[1]]
#> [1] "AB"
#> 
#> [[2]]
#> [1] "BB"
